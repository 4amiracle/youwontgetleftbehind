# You Won't Get Left Behind

AI learning, change and behavior management, and building together, for humans first.

- Local preview: `bundle exec jekyll serve` → http://localhost:4000/youwontgetleftbehind/
- Publish: double-click `Publish.command` (or push to `main`)
- New post: add a file to `_posts/` named `YYYY-MM-DD-title.md` with `categories: learn` or `categories: lead`
- Idea box: paste a Tally/Google Form link into `idea_form_url` in `_config.yml`
